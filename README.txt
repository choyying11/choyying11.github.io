# Choy Ying Portfolio — GitHub Pages

## Publish
1. Open your repository: https://github.com/choyying11/choyying11.github.io
2. Choose **Add file → Upload files**.
3. Upload `index.html` from this folder to the repository root.
4. Commit the change to the `main` branch.
5. Wait a few minutes and visit https://choyying11.github.io/

## Before sharing with recruiters
- Replace the email placeholder `ADD-YOUR-EMAIL-HERE`.
- Add your LinkedIn URL.
- Add a professional photo if desired (update the profile placeholder in `index.html`).
- Confirm work history, dates, and project descriptions against your résumé.
- Replace starter project links with real public project repositories.
- Never publish confidential company data, internal screenshots, customer information, or proprietary code.

The site is a responsive, single-file HTML/CSS/JavaScript portfolio and does not require a paid theme or build tools.
